# ⚔ Depths of Sosaria

ウルティマオンライン(UO)風の**スキル制**を核にした、ブラウザで動くダンジョンクローラー / ハックアンドスラッシュ。

レベルも経験値もありません。**剣を振れば剣術が、掘れば採掘が上がる** — 行動がそのままキャラクターを作ります。

## 遊び方

ビルド不要。`index.html` をブラウザで開くだけで遊べます(ダブルクリックでOK)。

```
# ローカルサーバーで開く場合
python3 -m http.server 8000
# → http://localhost:8000
```

## 操作

| キー | 動作 |
|---|---|
| WASD / 矢印 | 移動(敵が射程内にいれば自動で攻撃) |
| E | 調べる — 階段▼▲を昇降 / 宝箱📦を開ける / 鉱脈◆を採掘 |
| 1〜5 | 魔法(マジックアロー / ヒール / ファイアボール / ライトニング / グレーターヒール) |
| B | 包帯で手当て(治療スキル) |
| H | 隠密(もう一度押すと解除) |
| M | 瞑想(マナ回復。移動・被弾で中断) |
| C | スキルパネル |
| I | 装備・所持品 |

## スキルシステム(UO準拠)

- **使うと上がる**: スキルは 0.0 → 100.0(グランドマスター)。使用時に成長判定があり、行為の難易度が今の腕前に見合っているほど上がりやすい。格下の敵をいくら斬っても腕は上がりません。
- **合計キャップ 700**: 全10スキルの合計は700まで。GMにできるのは7スキルぶんだけ。
- **スキルロック**: スキルパネルの ↑(成長)/ ↓(下降許可)/ 🔒(固定)を切替え。キャップ到達後は「↓のスキルを削って別のスキルを伸ばす」UOの醍醐味をそのまま再現。
- **ステータスも行動で成長**: STR / DEX / INT(合計キャップ225)は関連スキルの使用で自然に上がる。STR→HP・打撃、DEX→攻撃速度・包帯速度、INT→マナ。

## ゲームループ

1. **キャンプ**で装備を整え、地下ダンジョンへ(5階ごとにチェックポイント解放)
2. 潜って戦い、**金貨・武具・鉱石**を集める。深いほど敵は強く、戦利品は豪華に
   - 武器接頭辞: ルーイン 〜 **ヴァンキッシング**
   - 金属: アイアン 〜 **ヴァロライト**(深層でしか採れない)
3. 生きて帰れば戦利品は倉庫へ。**死ねば持ち物と金貨の3割を失う**(スキル・装備・倉庫は無事)
4. 鉱石を精錬し、鍛冶で自作装備を鍛える(高スキルで高品質=高ティア)

セーブはキャンプ帰還時に自動(localStorage)。

## 技術

- 素のHTML + CSS + JavaScript(Canvas 2D)。依存ライブラリ・ビルドなし
- `js/skills.js` — スキル成長・キャップ・ロックのコアロジック
- `js/dungeon.js` — 部屋+通路のフロア自動生成
- `js/combat.js` — UO風の命中式・スイングタイマー・魔法・包帯

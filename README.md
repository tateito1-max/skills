# ⚔ Depths of Sosaria

**ウルティマオンライン(UO)風スキル制 × ウィザードリィ風パーティ制**の、ブラウザで動くターン制ダンジョンクローラー。

レベルも経験値もありません。**剣を振れば剣術が、掘れば採掘が上がる** — 行動がそのままキャラクターを作ります。そして持てる荷物の重さは**筋力次第**。

## 遊び方

ビルド不要。`index.html` をブラウザで開くだけで遊べます(ダブルクリックでOK)。

```
# ローカルサーバーで開く場合
python3 -m http.server 8000
# → http://localhost:8000
```

## ゲームの流れ

1. **酒場**で最大6人のパーティを編成(剣士/射手/魔導士/僧侶/坑夫鍛冶。「おまかせ編成」あり)
2. ダンジョンを**ターン制**で探索(1歩=1ターン。敵の群れも1ターンに1歩動く)
3. 敵の群れと接触すると**ウィザードリィ風コマンド戦闘**(戦う/呪文/防御/アイテム/逃走)
4. 金貨・武具・鉱石を集めて生還 → 倉庫へ。**全滅すると携行品と金貨の3割を失う**
5. 死者は**寺院**で蘇生(スキルが高いほど高額)。鉱石は精錬して**鍛冶**で装備を自作

セーブはキャンプ帰還時に自動(localStorage)。

## 操作

| キー | 動作 |
|---|---|
| WASD / 矢印 | 1タイル移動(=1ターン)。敵に向かって歩くと戦闘 |
| E | 調べる — 階段▼▲を昇降 / 宝箱📦 / 鉱脈◆を採掘(2ターン) |
| R | 休息(10ターン。HP/MP回復、ただし敵は動く) |
| B | 包帯で手当て(一番の重傷者に、治療上手が巻く。3ターン) |
| H | 隠密移動の切替(発見されにくくなる。先制攻撃のチャンス) |
| 1〜6 | キャラクター詳細(スキル・装備・持ち物) |
| クリック | 画面下のパーティカード、戦闘コマンド |

## スキルシステム(UO準拠・キャラごと)

- **使うと上がる**: 0.0 → 100.0(グランドマスター)。行為の難易度が腕前に見合うほど成長しやすい。格下の敵をいくら斬っても腕は上がらない
- **合計キャップ 700**(1人あたり): GMにできるのは7スキルぶん。↑/↓/🔒ロックで「削るスキルを選んで伸ばす」UOの醍醐味を再現
- **ステータスも行動で成長**: STR/DEX/INT(合計225)。STR→HP・打撃・**所持容量**、DEX→行動順・逃走、INT→マナ

| 分類 | スキル |
|---|---|
| 戦闘 | 剣術・弓術・戦術・受け流し(盾) |
| 魔法 | 魔法・瞑想(マナ自然回復) |
| 補助 | 治療・隠密 |
| 生産 | 採掘・鍛冶 |

## パーティと隊列(ウィザードリィ風)

- **前衛/後衛**: 近接武器は前衛のみ。後衛は弓・呪文・回復で戦う。敵の近接攻撃も前衛に集中する(前衛全滅で後衛が晒される)
- 敵は「スケルトン ×4」のような**グループ**で現れ、複数グループのこともある
- 行動順はDEX基準のイニシアチブ。ファイアボールはグループ全体を焼く

## 重量システム

- すべてのアイテムに重さがあり、**所持容量 = 15 + STR × 1.5**(装備品も含む)
- 容量を超える物は持てない。「渡す」で仲間に分担、倉庫に預けて身軽に潜る
- 鉱石(重さ4/個)は嵩張る — 力自慢の坑夫が輝く

## 技術

- 素のHTML + CSS + JavaScript(Canvas 2D + DOM UI)。依存ライブラリ・ビルドなし
- `js/skills.js` — スキル成長・キャップ・ロック(コア)
- `js/battle.js` — ウィザードリィ風グループ戦闘
- `js/items.js` — 重量・分配・ティア付き戦利品
- `js/dungeon.js` — 部屋+通路のフロア自動生成
